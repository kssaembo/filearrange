# 검증 결과

- Linux / Python / PySide6 6.11.2에서 코어·UI 테스트 25개 통과.
- Windows 전용 2개(DPAPI 저장, 260자 이상 경로 이동)는 플랫폼 제한으로 미실행. Windows 빌드 워크플로에서 실행하도록 구성.
- Qt 오프스크린 창 생성, 한글 파일명 표 표시, 실제 worker 스캔 완료와 버튼 활성화 확인.
- docs/review-screen.png는 테스트 파일과 모의 추천 결과를 넣은 실제 Qt 화면. 실서비스 Gemini 결과가 아님.
- 실제 Gemini 연결, Windows 단독 EXE 빌드·실행, 서로 다른 드라이브 간 이동은 이 환경에서 미검증.
- 핵심 테스트: 충돌·경쟁 생성 덮어쓰기 방지, 파일 변경 거절, 취소, 이동 전 저널, 부분 실패 복원, 복원 충돌, 숨김·링크·목적지 제외, 캐시, 잘못된 AI 응답, 개인정보 전송 필드 제한.
